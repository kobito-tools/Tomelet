# Tomelet bundled fonts

Tomelet ships the following fonts so its appearance does not depend on fonts installed in the operating system.

- Noto Sans Japanese: `NotoSansJP.ttf`
- Rounded M+ 1c: `RoundedMplus1c-Regular.ttf`
- Shippori Mincho: `ShipporiMincho-Regular.ttf`
- Yomogi: `Yomogi-Regular.ttf`

Each font is distributed under the SIL Open Font License 1.1. The corresponding license text is stored beside each font as `OFL-*.txt` and must remain with redistributed copies.

Source repositories:

- https://github.com/google/fonts/tree/main/ofl/notosansjp
- https://github.com/google/fonts/tree/main/ofl/roundedmplus1c
- https://github.com/google/fonts/tree/main/ofl/shipporimincho
- https://github.com/google/fonts/tree/main/ofl/yomogi
